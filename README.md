<h1 align="center">Go Attendance Mon</h1>


A Attendance monitor, A Telegram bot to monitor the attendance to aim for Required Attendance by the Academy. 
```text 
Go Network Mon, Use Ping, It`s Super effective.
```

> [!note]
> The name is inspired by Pokémon.


> [!important]
> This project is primary build to be hosted by docker and used in linux. I can not garentee cross platfrom support.


## Telegram Bot
A telegram bot that will help you monitor your attendance. May it be per day or per subject. It will help you estimate how many consicutive day you need to go or how many leaves you can take based on your attendance.
