# Architecture


The project follows a standand webhook based `telegram bot` func. The telegram will create a webhook event to the vercel when there is a new message. 


## Appwrite

The project will be using `appwrite` for database and storing information.

The Project will calculate total attendace percentage Per day or per subject as configured. It will help estimate when to go or not to meet the acemdy's required attendance percentage.
